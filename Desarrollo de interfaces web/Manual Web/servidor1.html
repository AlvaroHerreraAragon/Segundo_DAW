Apache Tomcat 10.1 en Windows 11

Instalación y configuración para ejecutar una aplicación web Java.

Inicio Requisitos Descarga Instalación y configuración Prueba de funcionamiento

1. ¿Qué es Apache Tomcat?

Apache Tomcat es un servidor web y contenedor de aplicaciones que permite ejecutar aplicaciones web Java mediante tecnologías como Servlets y JSP. Esta guía explica cómo instalarlo en Windows 11 y comprobar que puede ejecutar código Java.

2. Requisitos previos

  • Windows 11.
  • Conexión a Internet para descargar el software.
  • Java JDK 21. Tomcat 10.1 requiere Java 11 o una versión posterior.

Instalar y comprobar Java

  1. Descarga el JDK desde la página oficial de Eclipse Temurin. Selecciona JDK 21 para Windows x64.
  2. Ejecuta el instalador y completa la instalación.
  3. Abre el Símbolo del sistema (CMD) y ejecuta:
java -version 
javac -version

Los comandos deben mostrar la versión instalada. Si no se reconocen, configura las variables de entorno de Java: crea JAVA_HOME con la ruta de la carpeta del JDK y añade %JAVA_HOME%\\bin a la variable Path. Abre un CMD nuevo y vuelve a comprobar los comandos.

3. Descargar Apache Tomcat

  1. Abre la página oficial de descargas de Apache Tomcat 10.
  2. Busca la versión 10.1 y el apartado de distribuciones binarias para Windows.
  3. Descarga el instalador de Windows con extensión .exe.

4. Instalar y configurar Tomcat

  1. Ejecuta el archivo .exe descargado y acepta la licencia.
  2. Mantén los componentes predeterminados del asistente.
  3. Cuando solicite el puerto HTTP, utiliza 8080, salvo que esté ocupado.
  4. Cuando solicite Java, indica la carpeta donde está instalado el JDK, si no se detecta automáticamente.
  5. Selecciona la carpeta de instalación y termina el asistente. Inicia el servicio de Tomcat si el instalador ofrece esa opción.

Comprobar que el servidor está iniciado

Abre un navegador y visita:

http://localhost:8080/

Si aparece la página de bienvenida de Apache Tomcat, el servidor está funcionando.

5. Ejecutar código Java mediante JSP

  1. Dentro de la carpeta de instalación de Tomcat, abre webapps.
  2. Crea una carpeta llamada PruebaJava.
  3. Dentro, crea un archivo llamado index.jsp. Comprueba que no termine en .txt.
  4. Copia este contenido en el archivo y guárdalo:
<%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Prueba Java</title>
</head>
<body>
    <h1>Tomcat funciona correctamente</h1>
    <%
        String mensaje = "Java se está ejecutando en el servidor";
    %>
    <p><%= mensaje %></p>
</body>
</html>

Abre esta dirección en el navegador:

http://localhost:8080/PruebaJava/

Debe aparecer el encabezado «Tomcat funciona correctamente» y el mensaje generado mediante código Java. Esto comprueba que Tomcat está ejecutando una página JSP.
